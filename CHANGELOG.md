# Changelog

This changelog starts with the first version requested for the project (`0.0.1`) and records the current version (`0.1.0`). No separate release notes are available for intermediate versions, so they are not listed as published releases.

## 0.1.0

- Add configurable filter groups for note age, folder, tags, and frontmatter properties.
- Add daily review selection, a configurable review limit, and a note count command.
- Add customizable review actions, including move, delete, tag, property, snooze, template, and today's-note actions.
- Add action icons, colors, keyboard shortcuts, cover images, and French interface support.

## 0.0.1

- First requested version: initial daily note review prototype for selecting and sorting notes in Obsidian.
